# Игровой сервер «Нити» (бесплатный запуск на Render)

Маленькая программа, которая передаёт игрокам сообщения друг другу. Работает вместо Supabase для игр.
Пока адрес сервера не вписан в `js/tanks.js` (`TK_SERVER`), игра работает как раньше.

## Как запустить бесплатно (≈5 минут, карта не нужна)
1. Загрузите папку `gameserver` на GitHub (она уже в проекте — просто сделайте push).
2. Зайдите на https://render.com (через VPN), войдите через GitHub.
3. New → **Web Service** → выберите репозиторий «Нити».
4. Root Directory: `gameserver`; Build Command: `npm install`; Start Command: `npm start`; Instance Type: **Free**.
5. После деплоя Render покажет адрес вида `https://nit-games.onrender.com`.
6. В `js/tanks.js` впишите `const TK_SERVER='wss://nit-games.onrender.com';` и сделайте push.

## Что учесть
* Бесплатный Render «засыпает» через 15 минут без игроков; первое подключение после сна занимает до минуты. Игра будит сервер сама при входе в лобби и, если не вышло, переходит на прежний способ.
* Все игроки одной комнаты должны попасть на один и тот же сервер; если у кого-то он не ответил, он окажется в «старой» комнате отдельно — просто перезайти.
* Сервер — ретранслятор: он не считает игру, поэтому пинг = дорога до сервера. Хостинг выбирайте ближе к игрокам (на Render — Frankfurt).
* Проверка: открыть адрес сервера в браузере — должно быть «nit game server ok».
